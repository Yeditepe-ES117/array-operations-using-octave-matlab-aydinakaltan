# Assignment 1: Array Operations using Octave/MATLAB

Create a function that changes the third element of an array given by the user. The function accepts a 1-D vector which has larger than three elements, then it makes the third element 0, and returns the changed vector.

The function name must be myfunc. Please be careful about the letters, because if you write the function name or other given parameters, then your work will not be evaluated.

Please write your function in a file called myfunc.m. Otherwise, you will not be evaluated.
